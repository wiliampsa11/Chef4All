# Chef4All

Web de recetas con una portada para explorar platos (enchiladas, paella, salmorejo, canelones…) y una página de detalle para las enchiladas.

**Demo:** https://wiliampsa11.github.io/Chef4All/

## Tecnologías
- HTML5 y CSS3 (maquetación en columnas, Google Fonts)
- JavaScript para la barra de navegación que cambia de color al hacer scroll

## Estructura
```
index.html          Portada con todas las recetas
pages/              Página de detalle (enchiladas)
css/                Estilos de la portada y de la página de receta
js/script.js        Efecto de la barra de navegación
img/                Foto de las enchiladas
```

## Fotos
Las fotos de las recetas son de Wikimedia Commons, con licencias libres (CC0, CC BY y CC BY-SA). El autor y la licencia de cada una aparecen en su tarjeta.

## Cómo verlo
Abre `index.html` en el navegador o visita la demo.
